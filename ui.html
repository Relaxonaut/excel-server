Excel-Server

1. Verbindung (einmal pro Excel-Datei)

  1. In Excel einen Namen für den Datenbereich anlegen (Formeln → Namens-Manager → Neu): Name , Bezug z.B. =Tabelle1!$A$1:$Z$200. Der Bereich muss bei A1 beginnen, damit die Zelladressen (G20 …) stimmen.
  2. Daten → Neue Abfrage → Aus anderen Quellen → Leere Abfrage → Erweiterter Editor → diesen Code einfügen:
  3. Abfrage in Ergebnis umbenennen und als Tabelle laden – auf einem anderen Blatt als die Daten.
  4. Aktualisieren: Daten → Alle aktualisieren. Automatisch: Abfrageeigenschaften → „Alle X Minuten“ / „Beim Öffnen aktualisieren“.

2. Mit einer Excel-Datei testen

Die Datei wird nur im Speicher gelesen und nicht gespeichert.

Einstellungen sichern

Auf dem kostenlosen Render-Plan gehen gespeicherte Einstellungen bei jedem Neustart verloren. Kopiere diesen Text in Render unter Environment als Variable SETTINGS_JSON, dann sind sie dauerhaft.
