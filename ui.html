Excel-Server

1. Verbindung (Excel)

  1. In Excel einen benannten Bereich anlegen. Name: Bezug beispielsweise: =Tabelle1!$A$1:$Z$200
  2. In Power Query eine leere Abfrage anlegen.
  3. Abfrage in Ergebnis umbenennen und als Tabelle laden.
  4. Mit Daten → Alle aktualisieren aktualisieren.
